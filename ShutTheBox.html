The number is: 0
How to Play Shut The Box:
1. Click on the generate number button

2. Create the total needed by using the number buttons

3. Once you have made the total, click on the check total button and see if you have it correct

4. If it is correct the buttons will be disabled, if wrong the buttons will be re-enabled and you need to try again

5. Keep on repeating this process until you have either won the game or you can longer play

Won. If you have disabled all the buttons click the check game button and it will alert you have won and reset the game

Lost. If you have still got buttons left bt can't do anything then click the reset game button and the game will reset itself
